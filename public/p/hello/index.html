开站第一篇：为什么建这个小站

50 岁，给自己搭一个放文章的地方

2026-11-13

今天这个站正式开张。

为什么要在 GitHub 上建一个自己的网站？三个原因：

第一，笔记需要一个出口。 我记了很多年笔记，从纸质的到印象笔记，存了几千条。笔记的价值不是存，是整理之后能被看见、被用上。从这个站开始，把值得分享的部分陆续整理出来。

第二，经验需要沉淀成文章。 干质量这行十几年，Excel、Power BI、数据分析，攒了不少实战的东西。写出来，一是逼自己想清楚，二是万一哪天换赛道，这些就是底牌。

第三，试试新工具。 这个站是用 Hugo 搭的、放在 GitHub Pages 上，写文章就是往仓库里丢一个 markdown 文件。整套流程是 WB 帮我搭的，我负责写，它负责发布——这正是我想要的分工。

后续打算写这几类东西：

  • 质量与数据：工厂里的数据分析实战
  • 跑步与健康：一个 50 岁人的减重跑步记录
  • 游戏笔记：Warframe 之类的玩家心得
  • 随笔：想写什么写什么

不赶时间，慢慢写。
